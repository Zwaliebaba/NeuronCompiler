This started as a list of open questions. All but one were decided on 2026-11-23; the decisions are recorded here with their consequences, and the affected documents have been updated. New questions get appended with status *open*.

| Q-28 | Conformance gates and their tool versions | **`make check-format`, `make tidy` and `make check-tree` gate CI on the Linux Clang leg. clang-format and clang-tidy are pinned to LLVM 18.1.3**, the version ubuntu-24.04 installs; the targets refuse to run under any other. `clang-analyzer-security.insecureAPI.DeprecatedOrUnsafeBufferHandling` is excluded. `check-tree` is `src/tools/checktree.c`, built by stage 0. | A runner image moving LLVM cannot turn `main` red with no code change; a version bump is its own change, re-measured. | Q-30 | Phase-1 plan (the re-plan Q-02 called for) | **Twelve ordered milestones, 1.1–1.12, each with an oracle as its exit; a walking skeleton runs C end to end at 1.6; the back end is driven by textual NIR first.** A PR adds at most about 2,500 lines of non-test, non-table code. Velocity is re-measured at 1.4 and 1.6. | Phase 0's elapsed time (4 h 22 min) is not extrapolated: its oracles were exact and its scope had no integration above it. Review checks scope and design, and correctness rests on the oracles, so a milestone without an executable oracle is not ready to start. Tests that need the UCRT or SDK headers run only in the `windows-arm64` job. | [15](15-roadmap.md) §5 |
| Q-31 | Core II conventions (milestone 1.1): diagnostics numbering and arguments, columns, hash maps | **Diagnostics:** one table, `src/core/diag.def`; numbers `NC1xxx` fatal, `NC2xxx`–`NC3xxx` error, `NC4xxx` warning (the `cl` convention), `NC0xxx` internal errors, notes unnumbered; a row is never removed or renumbered. Messages take typed `%0`–`%9` arguments, not `printf` formats. A fatal diagnostic is recorded, not acted on: the caller stops. **Columns** are 1-based and count UTF-8 code points, a tab counting one. **Hash maps** (`core/hmap.inc`) are Robin Hood with backward-shift deletion and a 7/8 load limit, and have no iteration function at all. The hash is FNV-1a with the splitmix64 finalizer. | No `__attribute__((format))` is needed (R12), and a message cannot disagree with its arguments. A unit test holds every row to its number range and checks that numbers are unique. Without an iteration function, R15's "no hash map is iterated for output" cannot be broken by accident; code that visits every entry keeps a vector in insertion order. Whether the VS error list places a caret by code points or by UTF-16 units is unverified, and is checked on Windows when 1.6 first reports a diagnostic in non-ASCII source. Deferred to 1.5: `#line`, `#pragma warning(push/pop)`, and reusing a file's bytes across repeated inclusions. The first Windows run added a dialect rule: an enumerator without a fixed underlying type must fit in `int` (Design/13 §1). | [02](02-architecture.md) §3, [12](12-driver-and-toolchain.md) §6, [13](13-self-hosting-bootstrap.md) §1 |
